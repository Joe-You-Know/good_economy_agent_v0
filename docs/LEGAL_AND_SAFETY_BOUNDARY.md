# Legal and Safety Boundary

This scaffold is not legal advice. It is a technical methodology for an experiment.

## Baseline Prohibited Actions

The baseline agent must not:

- spam,
- impersonate humans,
- deceive,
- blackmail,
- threaten,
- harass,
- create fake traffic,
- create fake clicks,
- create fake referrals,
- evade anti-bot systems,
- violate platform terms,
- scrape prohibited sources,
- collect personal data without consent,
- sell restricted/high-risk products,
- provide medical/legal/financial professional advice,
- hide fees,
- create hard-to-cancel billing,
- use paid ads before earning money,
- use personal networks,
- self-pay,
- collude.

## Allowed Baseline Channels

- public-good bounties,
- open-source issues,
- documentation improvements,
- accessibility patches,
- education artifacts,
- open-science reproducibility aids,
- local-only artifact generation,
- public free tools,
- voluntary donation/sponsorship links,
- opt-in marketplace listings.

## Accountability Model

The AI is evaluated as the operational decision system.

The human builder/deployer remains accountable for:

- model choice,
- tool permissions,
- safety boundaries,
- legal wrapper,
- logging,
- cost controls,
- deployment decision,
- failure modes.

## Disclosure Principle

If the agent interacts externally in future live versions, it should disclose that the communication or artifact is AI-operated or AI-generated when that fact is material to trust, consent, or transaction.
